# DMLv4 需求收集方案

## 开发DMLv4需要收集哪些信息？

1. 业务流程介绍

2. 具体功能描述

3. 现有系统优缺点

4. 要去除的功能

4. 用户期待的新功能

## 如何实现这些信息收集？

1. 业务流程介绍，请以下人员详细描述工作流程（与DML系统相关，不需要介绍实际操作手法。操作手法在\#2号问题内解答）

    1\.1 测试部领导

    1\.2 Lab负责人（每个lab介绍自己lab）

    1\.3 TPM

    1\.4 测试人员

    1\.5 自动化开发人员

    1\.6 测试用例/需求编辑人员

    1\.7 数据消费和数据产生接口



2. 具体功能描述：以下模块/界面需要详细介绍使用流程（按角色，每个角色找2\-3个用户，如实介绍自己的使用手法）。用到了哪个功能，就到对应的单元格内填写以下信息：

    1. 这个界面里你是怎么使用的（越详细越好）。如果没有使用，也要说明：不使用。

    2. 这个界面里哪个功能是你喜爱的，新系统一定要保留。

    3. 这个界面里哪个功能还需要完善

    4. 这个界面里还应该有什么功能

    5. 可以截图\+文字说明
