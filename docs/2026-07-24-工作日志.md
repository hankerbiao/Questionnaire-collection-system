- Compose 仅包含 `frontend` 和 `backend`，MongoDB 使用外部连接。
- 前端使用 Node 多阶段构建和非特权 Nginx，后端使用 uv 同步锁定依赖并以非 root 用户运行。
- 解决中文项目路径导致的 Docker Buildx gRPC header 异常，增加 `docker/compose.sh` 作为 ASCII 路径兼容入口。
- 容器健康检查、重启策略、SPA fallback 和 API 反向代理已配置。

### 7. 统一快速更新脚本

- 新增 `docker/redeploy.sh`，整合前端和后端更新。
- 支持 `frontend`、`backend`、`all` 三种目标，无参数时默认为 `all`。
- 复用 Docker 构建缓存，只替换镜像发生变化的容器。
- 完整部署时先等待后端就绪，再更新前端。
- 容器不健康或等待超时时，自动输出对应服务日志。
- 部署完成后输出问卷、管理后台、API 健康接口、Docker 内部后端及局域网地址。

## 常用命令

```bash
# 默认检查并更新前后端
./docker/redeploy.sh

# 只更新指定服务
./docker/redeploy.sh frontend
./docker/redeploy.sh backend

# 测试通过后再更新
./docker/redeploy.sh all --check

# 查看状态和日志
./docker/compose.sh ps
./docker/compose.sh logs -f
```
